Browser extensions for Chrome & Firefox

Capture screenshots from any page and send them straight to ImageTools — or just grab a region to your clipboard. Manifest V3 for Chrome, WebExtensions for Firefox, same capture UX in both.

Install instructions Pairing flow Source on GitHub ↗

Features

👁️

Capture visible area

Grabs exactly what's on screen right now. A preview modal opens before anything leaves your browser — copy it, upload it, or discard it.

📜

Capture full page

Stitches the entire scrolling page into one tall image, correctly scaled even under DevTools device emulation and on HiDPI displays.

✂️

Capture selection

Drag a region on the page. An action panel appears with tag picker and 📋 Copy / ✓ Capture / Reselect / Cancel. Esc cancels, Enter captures, Ctrl/Cmd+C copies.

📋

Copy vs. lodge

Every capture can go one of two ways: 📋 Copy puts the PNG on your system clipboard entirely client-side (nothing is uploaded), while ✓ Capture / ✓ Upload lodges it with your ImageTools instance.

🏷️

Tag uploads

Set a default tag in the popup ("Tag uploads as"), pick from up to 8 recent-tag chips in the capture overlay, or type a brand-new one. Untagged uploads are fine too — just clear the tag.

🔐

OAuth-style pairing

A short-lived, single-use registration URL pairs the extension with your session. No passwords are typed into the extension; tokens are revocable from the web UI at any time.

Context menu too Right-click anywhere on a page for capture actions, in addition to the extension popup. Only one overlay/modal is ever active — repeat captures never produce duplicate uploads.

Pairing flow (generate → paste → connect)

Connecting an extension to your ImageTools instance takes about fifteen seconds:

  1. Open the addon settings in the web UIOpen ImageTools in your browser, go to Settings (About modal) → click Browser Addon.
  2. Generate a registration URLClick Generate Registration URL. The backend creates an authorization code with a 5-minute expiry.
  3. Paste it into the extensionClick the ImageTools extension icon, paste the registration URL into the field, and click Connect.
  4. Capture awayThe extension exchanges the code for an access token (30 days) and a refresh token (90 days), then uses the access token for all uploads — refreshing automatically when it expires.

What happens under the hood

StepDetail
Authorization codeSingle-use, expires after 5 minutes
Access tokenIssued on exchange, valid 30 days, used for screenshot uploads
Refresh tokenValid 90 days; silently obtains a fresh access token
StorageTokens live in browser storage; never in the page DOM
RevocationRevoke any connected addon from the ImageTools settings — effective immediately

The addon talks to these backend endpoints: POST /api/v1/addon/authorize, /token, /refresh, /upload, plus list/revoke endpoints for managing authorizations.

Install instructions

Store publishing is on the roadmap; for now both extensions are installed manually from the repo.

Chrome / Chromium

  1. Get the extension folder: clone the repo (browser-addons/chrome/) or grab dist/imagetools-chrome-1.12.0.zip from a release build and unzip it.
  2. Open chrome://extensions/.
  3. Enable Developer mode (top-right toggle).
  4. Click Load unpacked and select the chrome folder.
  5. The ImageTools icon appears in the toolbar — pin it if you like.

Firefox

  1. Get the extension folder: browser-addons/firefox/ from the repo, or the packaged dist/imagetools-firefox-1.12.0.zip.
  2. Open about:debugging in Firefox.
  3. Click This Firefox → Load Temporary Add-on.
  4. Select the manifest.json file inside the firefox folder.
  5. Note: temporary add-ons are removed when Firefox closes — reload the same way after a restart (signed XPI packaging is on the roadmap).

Capture UX in detail

  • Selection overlay: action panel shows a Tag input pre-filled with the popup's current tag, up to 8 recent-tag chips above the buttons, then 📋 Copy / ✓ Capture / Reselect / Cancel. Typing in the tag input never triggers page keyboard shortcuts.
  • Preview modal (visible area & full page): nothing uploads until you confirm. The modal shows the captured image, tag picker, and 📋 Copy / ✓ Upload / ✕ Discard — and the modal itself is not part of the capture. Full-page previews scroll so you can check the whole stitch.
  • Clipboard copy: entirely client-side; pairing isn't required for the copy path, nothing is uploaded, and the popup's current tag is untouched. Paste into any image-capable target (editor, Slack, etc.).
  • Failure handling: if the backend is down, the preview modal stays open with an error and a Retry button — Discard still works.

Security notes

  • No shared secrets: pairing uses a single-use authorization code that expires in 5 minutes — the extension never sees your password.
  • Short-lived access tokens: access tokens last 30 days, refresh tokens 90 days; both are stored in browser storage only.
  • Server-side control: every pairing is listed in ImageTools settings and can be revoked there at any time — subsequent uploads fail immediately.
  • Copy is local: the 📋 Copy path performs no network upload at all; only ✓ Capture / ✓ Upload contacts your instance (with the bearer access token).
  • Least privilege: the extensions request only the permissions needed for capture and API calls — review the manifests in browser-addons/chrome/manifest.json (MV3) and browser-addons/firefox/manifest.json.

Development

Both builds share the same structure: background.js (service worker / background script for auth and capture), popup.html/js, content.js (selection overlay), and icons. Load them unpacked/temporarily as above for live testing — see MANUAL_TEST.md for the manual test plan covering edge selections, device emulation, tagging and clipboard copy.
